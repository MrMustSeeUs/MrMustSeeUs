## Currently Building

### 🔨 Collaborative Code Sandbox
A real-time, multi-user code editor usable by anyone with zero setup — no login, no signup, no server-side execution risk.

- **Real-time sync:** Yjs (CRDT) over a lightweight Node.js WebSocket relay
- **In-browser AI:** Python execution via Pyodide (WebAssembly) running live ML inference client-side — no backend AI calls, no API costs, nothing to ever shut off
- **Data layer:** Neon serverless PostgreSQL for anonymous snippet/session storage — no user accounts, nothing to leak
- **DevOps:** GitHub Actions running tests, linting, and Trivy container scans on every push
- **Deployment:** Dockerized relay on Railway, static frontend on Cloudflare Pages
- **Design constraint:** built to run indefinitely with zero maintenance — no paid APIs, no floating dependency versions, no server-side attack surface
